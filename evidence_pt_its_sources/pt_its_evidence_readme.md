# SEA 22 Cities Public Transport and Signal/ITS Supplement

This package supplements the 22-city Southeast Asia traffic-performance paper with two contextual variables requested by the ATS editor:

1. Public transport supply / mode-share proxy.
2. Signal coordination / ITS management proxy.

## Main files

- `SEA_22Cities_PT_ITS_Master_v1.xlsx`: Excel workbook with master data, sources, evidence log, scoring rules, validation and issues.
- `master_PT_ITS_supplement.csv`: machine-readable master table.
- `source_registry.csv`: source list with URLs and downloaded-source file names where available.
- `evidence_log_long.csv`: city-variable-source long table.
- `scoring_rules.md`: score definitions.
- `validation_report.md`: three-round data check.
- `issues_to_resolve.md`: rows and methodological issues that still need attention.
- `sources/raw_downloads/`: downloaded source PDFs/TXT when direct download was available.

## Important methodological note

The scores are evidence-based proxies. They do not represent measured percentages of public transport supply or coordinated signal-control coverage. Use them for exploratory contextual diagnosis, not causal inference.
